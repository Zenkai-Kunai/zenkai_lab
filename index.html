FAQ

Frequently Asked Questions

What does the RM500+ Full FYP Prototype package include?

It can include hardware integration, ESP32/Arduino development, sensors, modules, firmware, IoT connectivity, basic dashboards, prototype assembly, testing and debugging. Final scope depends on the project.

Are components included in the package?

Components are normally quoted separately. This allows the project cost to be calculated based on the actual hardware required.

Can I use my own components?

Yes. Existing components can be used if they are suitable for the project.

Can you help with an existing broken prototype?

Yes. Hardware debugging, firmware troubleshooting, wiring problems and sensor/module issues can be investigated.

Can you develop the prototype while I handle my academic work?

Yes. ZENKAI focuses on technical prototyping and development. Students should remain responsible for their own academic documentation, understanding, presentation and submission requirements.

How much does a complete project cost?

The RM500+ package is only a starting point. More complex projects involving multiple devices, custom PCBs, databases, advanced dashboards or extensive development may cost RM800 or more.
